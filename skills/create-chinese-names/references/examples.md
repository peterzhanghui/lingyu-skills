# 起名规则正反例

示例只用于说明单项规则，不代表姓名适合所有家庭，也不构成对重名、方言或户籍可用性的保证。实际生成时必须结合姓氏和用户条件重新检查。

## 音律示例

### 较好：张景和

- 读音为 `zhāng jǐng hé`，声调是一、三、二，对应“平—仄—平”。
- 名字末字“和”为二声，整体有起伏，收音相对舒展。
- `zh / j / h` 的声母以及 `ang / ing / e` 的韵母没有连续重复。
- “景”与“和”可共同指向明朗、和悦的气质，组合语义能够成立。

仍需检查：“和”存在少数其他读音和用法；在姓名语境通常读 `hé`，但若执行严格的“完全无多音字”标准，应将其降为谨慎或换字。

### 较差：张浩昊

- “浩、昊”都读 `hào`，声母、韵母和声调完全重复，连读显得黏连。
- 两字视觉和读音相近，辨识度不足。
- “浩”属于默认高频字，“昊”又带较大的天空意象，组合容易显得用力过满。

### 较差：张乐行

- “乐”可读 `lè / yuè`，“行”可读 `xíng / háng`，读音不稳定。
- 陌生人难以仅凭字面确认读法，容易在点名、登记和交流中反复解释。

## 字形示例

### 较好：林知远

- 三字均为常见规范字，日常书写和输入较方便。
- 左右、上下/半包围等视觉形态存在变化，整体没有连续堆叠复杂部件。
- “知”与“远”形成“见识长远”的连贯方向。

仍需检查：精确笔画应以选定的规范字表为准；不能只凭肉眼宣称全部落在某个笔画区间。

### 较差：丁曦懿

- 姓氏极简，而名字两字笔画密集，前后视觉重量反差很大。
- 日常书写成本高，也更容易写错或被录错。
- 即使单字寓意积极，整体仍不符合“简单好写、结构匀称”的优先原则。

## 字义示例

### 较好：周清宁

- “清”与“宁”都指向清朗、安宁的气质，属于同一语义方向。
- 两字不是机械同义重复，而是“清澈平和”的互补组合。

仍需检查：完整姓名声调为一、一、二，音律起伏弱于“平—仄—平”；若音律优先，可继续寻找替代字。

### 较差：周锐柔

- “锐”偏锋利进取，“柔”偏温和柔顺；若没有明确的“刚柔并济”命名意图，组合容易显得割裂。
- 两个单字分别有正面含义，不代表组合后自然。

## 尺度和流行度示例

### 较差：王宇宙

- “宇宙”是固定常用词，尺度过大，容易产生戏谑感。
- 不能因为两个字都有宏阔意象就认为组合适合人名。

### 谨慎：李梓轩

- 字义本身不负面，书写识别也不困难。
- “梓、轩”及“子轩/梓轩”有上一轮全国姓名数据和历史热门组合支持，属于历史爆款与模板化风险，不应冒充最新全国排行。
- 不要宣称“绝对不能用”；完成音、形、义检查后，可将其列为“可选”，说明历史高频风险并提供同风格替代方案。

## 谐音与家庭避讳示例

### 较差：杜子腾

- 完整姓名连读容易联想到“肚子疼”，属于明显负面谐音，应直接排除。

### 需要用户确认：陈景明

- 普通话音、形、义可以通过基础检查，也不能据此直接推荐。
- 若家中长辈名为“景明”，则命中家庭避讳；Skill 不应自行猜测，必须请用户提供或确认避讳名单。

## 迷信配字反例

### 较差做法

“生肖属龙，所以姓名必须带水；五行缺木，所以一定要用三个木字旁。”

问题在于：把文化习俗当成确定性规则，可能强行加入生僻、拗口或语义割裂的字，反而忽略姓名最基本的好听、好写和好理解。

### 推荐做法

如用户重视生肖或五行，将其作为家庭文化偏好记录；先保证常用字、读音、字形和语义质量，再在多个合格候选中温和体现相关意象，并明确不作吉凶保证。
