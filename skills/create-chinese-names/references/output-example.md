# 标准输出示例

下面只演示格式和信息密度。不要机械复用示例姓名、出处或八字判断；实际内容必须根据用户条件重新生成和核验。

方案一

姓名：张映泉

拼音声调：zhāng yìng quán，第一声、第四声、第二声，声调结构为“平—仄—平”，读音起伏清楚，收尾舒展。

八字匹配：“泉”带有清润、流动的文化意象，可在用户重视传统五行时作为温和参考，但不等同于确定性的“补水”。

匹配建议：“映、泉”共同构成泉水映照的明澈画面，语义连贯，两个字均较常见，日常书写和识别方便。没有强行依附古籍出处；仍需结合家人常用方言确认是否存在特殊谐音。

——

方案二

姓名：张砺恒

拼音声调：zhāng lì héng，第一声、第四声、第二声，声调结构为“平—仄—平”，读音端正有力。

八字匹配：不刻意使用五行偏旁，主要以磨砺、持恒的稳定气质平衡整体命名方向。

匹配建议：“砺”指磨炼，“恒”指持久，两字形成由行动到品格的递进关系，辨识度较好。“砺”是规范字但日常使用频率低于“励”，实际使用时偶尔需要解释写法。

## 格式检查

- 使用中文方案序号。
- 每个方案只包含姓名、拼音声调、八字匹配、匹配建议四个字段。
- 方案之间使用单独一行的“——”。
- 不使用表格、分数、星级或重复的小结。
- 在匹配建议中同时呈现优势和需要斟酌的风险。
