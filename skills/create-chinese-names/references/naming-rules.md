# 中文个人姓名检查规则

## 约束优先级

按以下顺序处理冲突：

1. 姓氏、总字数、必须包含和明确避讳等硬约束。
2. 明显负面谐音、歧义、生僻难认、多音误读等风险。
3. 完整姓名的语义连贯性与读音流畅度。
4. 用户的风格偏好与文化联想。
5. 典故出处。出处是加分项，不是硬凑条件。

把规则分成两层：

- **硬性排除**：用户明确避讳、明显负面谐音、生僻难认、容易误读的多音字、语义明显割裂。
- **默认偏好**：6–15 画、平仄起伏、男孩尾字阳平、结构搭配、避免宏大含义，并降低高频字词的模板化和重名风险。偏好之间冲突时优先保证好读、好写、含义连贯；用户明确要求时允许调整，并说明取舍。

## 音

- 按完整姓名连读，不要只检查名字部分。
- 使用普通话四声：一声为阴平、二声为阳平、三声为上声、四声为去声；一、二声归为平声，三、四声归为仄声。
- 优先让完整姓名平仄相间、有起伏。三字姓名若姓氏为平声，优先尝试“平—仄—平”；例如“张”是一声，可优先从“张 + 三/四声 + 一/二声”的组合筛选。
- 男孩三字姓名默认优先让末字使用二声（阳平）；可重点尝试名字两字“四声 + 二声”的节奏。把这条作为风格偏好，不因追求声调而牺牲字义和自然度。
- 避免相邻字声母相同或韵母高度重复，尤其是连续重复造成含混、绕口或听辨困难的组合。不要为了形式上的完全不同而淘汰实际读起来流畅的名字。
- 检查姓与名、名字两字以及完整姓名连续读音，排除明显负面谐音。方言风险只能提示用户请家人按常用方言复核。
- 默认排除容易误读的多音字，如“行、乐、重”；只有用户明确接受且读音稳定时才保留，并标注预期读音。

## 形

- 优先选择常用、简单、好写、易录入的规范汉字，默认排除生僻字、异体字和容易写错的字。
- 单字以 6–15 画为优先区间；少于或超过该区间不自动淘汰，但必须检查整个姓名的书写负担。笔画口径可能因字表而异，无法核实时不要伪报精确笔画数。
- 让各字视觉重量大致均衡，避免前后笔画反差过大造成“头重脚轻”或“脚重头轻”。
- 搭配左右、上下、独体等不同结构，避免多个结构过密、部件高度重复的字连续出现。
- 同时检查繁简体、常见字形和输入法录入便利性，并提示可能影响户籍登记的字形风险。

## 义

- 分别解释单字常用义，再解释组合后的整体语义。
- 让名字两字围绕同一语义方向，形成互补或递进关系；“同一个意思”指语义连贯，不要求两个字成为同义词或重复表达。
- 优先选择日常语境中稳定、积极且不过度宏大的含义，避免两个单字各自很好、组合后却割裂。
- 检查姓名与姓氏连在一起是否产生新的歧义。
- 不把罕见古义当成当代唯一含义，也不以牵强拆字证明吉凶。

## 尺度、人物与家庭避讳

除非用户明确要求并接受相应风险，默认避免以下类型：

- **尺度过大或期待过重**：宇、宙、日、月、星、辰、尧、舜、禹、帝、天、霸、圣。
- **历史或现实人物联想过强**：帝王、名人姓名或高度识别性的同名组合。无法可靠确认同名情况时，标注“需进一步检索”，不要声称已排除全部名人。
- **家庭避讳**：长辈姓名及近亲常用名。只根据用户提供的名单检查，不自行猜测家庭关系。

“宇、辰”等字既可能命中宏大意象，也可能在特定年份高频。不要因为单字命中风险就自动淘汰；结合完整姓名判断语义尺度、流畅度和辨识度。

## 高频与模板化风险

不要维护没有年份和地区的永久“网红字黑名单”。使用 [popularity-data.md](popularity-data.md) 中带来源的分层数据：

- **近年区域高频**：只能说明某个年份、某个地区使用较多，不能外推为全国统一排行。
- **上一轮全国爆款**：说明曾有全国数据支持，但不等同于当前仍处高峰。
- **证据不足**：不标记为高频，只能在完整组合明显模板化时作定性提示。

命中高频字或高频组合时：

1. 标记 `流行高频` 或 `组合模板化`，说明对应年份、地区或历史数据。
2. 不因高频直接判为坏名字；继续完成音、形、义检查。
3. 若整体质量合格，可保留为“可选”，同时提供 1–2 个同风格、辨识度更高的替代方案。
4. 没有可靠数据时使用“可能较常见”等保守表述，不声称“全国爆款”或给出虚构排名。

## 出处

- 只有能够确认作品名称与原文关系时才标注具体出处。
- 区分“直接取自”“化用”和“文化联想”，不要混为一谈。
- 无法核验时不写具体篇名和原句，可将其作为普通语义解释。
- 引文保持简短，不大段复制受版权保护的现代作品。

## 常见风险标签

- `生僻难认`：日常识别或录入成本较高。
- `多音误读`：存在常见的其他读音。
- `谐音歧义`：完整姓名连读产生明显联想。
- `书写复杂`：笔画或结构组合造成较高书写负担。
- `语义过满`：寓意宏大、直白或给使用者带来过强期待。
- `流行高频`：常见搭配可能增加同名概率；没有可靠数据时只能定性提示。
- `组合模板化`：两个常见字形成反复出现的固定搭配，可能降低辨识度。
- `出处待核`：文化联想合理，但尚不能确认具体原文。

## 排序方法

不要给出缺乏数据依据的 96 分、98 分等数值。使用“优先推荐 / 可选 / 谨慎”三级，并列出触发的规则、优点和风险。硬约束不满足的候选直接排除，不进入推荐列表。

按以下顺序复核每个候选：

1. 是否含生僻字、易误读多音字、用户避讳字或明显名人/长辈同名。
2. 完整姓名是否有负面谐音，声母韵母是否连续重复。
3. 平仄是否有起伏；适用时是否满足“平—仄—平”或“四声 + 二声”的偏好。
4. 单字是否大致落在 6–15 画，整体结构是否匀称、好写。
5. 两个名字用字是否语义连贯，是否尺度适中。
6. 是否命中宏大字、带年份和地区依据的高频字，以及模板化组合；高频本身不作一票否决。
7. 出处是否真实可核；没有出处时，名字是否仍能凭日常字义成立。
